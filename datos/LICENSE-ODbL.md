# Datos de artículos: Open Food Facts (ODbL)

`articulos.json` es un subconjunto de la base de datos de [Open Food Facts](https://world.openfoodfacts.org):
código EAN, nombre, marca y formato de productos vendidos en España, descargados con `descargar_articulos.py`.

- La base de datos de Open Food Facts se publica con la licencia
  [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/), y sus contenidos con la
  [Database Contents License](https://opendatacommons.org/licenses/dbcl/1-0/).
- Este subconjunto es una base de datos derivada y se distribuye con la misma licencia ODbL 1.0: se puede usar,
  copiar y adaptar citando a Open Food Facts y manteniendo la licencia.
- La categoría y las marcas de «lleva lote» y «lleva caducidad» de cada artículo las añade el script según la
  categoría de Open Food Facts; las unidades por caja que usa la demostración son configuración de ejemplo, no datos
  de Open Food Facts.

El código del repositorio tiene su propia licencia (MIT, en `LICENSE`).
